# 🎮✨ SNAKE AND LADDER GAME ✨🎮

## 🧠 PROJECT OVERVIEW

This is a console-based Snake and Ladder game developed in C++, where two players compete against each other by rolling dice and moving across the board 🎲.

It demonstrates how core programming concepts like classes, inheritance, loops, functions, conditions, and random number generation are used to build an interactive game.

## 🕹️ HOW THE GAME WORKS

The game follows the traditional Snake and Ladder rules:

* Each player rolls the dice automatically
* A player must roll 6 to enter the board
* Players move forward based on dice value
* Landing on a ladder moves the player up
* Landing on a snake moves the player down
* Rolling a 6 gives an extra turn
* The first player to reach exactly 100 wins

---

## 🎮 GAME FLOW

The program follows a structured sequence to ensure smooth gameplay:

### 🚀 Start Game

Display game rules and initialize player positions.

### 🖼️ Open Board

Ask the user whether to open the board image before starting.

### 🎲 Player 1 Turn

Roll dice automatically and update position.

### 🔍 Check Position

Apply snake or ladder logic if needed.

### 🎲 Player 2 Turn

Roll dice automatically and update position.

### 🔁 Repeat Process

Continue alternating turns until one player wins.
